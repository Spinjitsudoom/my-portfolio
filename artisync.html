Features

From a folder of badly named files to a tagged library with cover art, one album at a time.

Three places to look albums up

Deezer is fast and needs no account, and it's the default. MusicBrainz needs no account either and lists every edition, but it's slower. Spotify needs a free developer app. If Spotify pauses your app for making too many requests, ArtiSync says for how long and offers to switch to Deezer.

Your whole library

Choose the folder that holds your artist folders and the Library lists every artist and album, marked not opened yet, needs attention, or done. It remembers, opens the first unfinished album, and Next album moves on through the rest.

Matching that copes with messy names

Each album folder is matched to the right release by its name and year, and each file to a track, even when it's called track 4 - welcome home sanitarium.mp3. Every track shows how confident the match is.

Fix anything by hand

Pick a different release from the Releases column, with its artwork. Type to filter it, or press Enter to search the whole source for albums filed under another artist. Change and Assign to pair files and tracks yourself.

Rename & Tag in one go

Renames the files and writes the title, artist, album, year, genre, track numbers and cover art into MP3, FLAC, M4A and OGG files. Names are 01 - Title.mp3 (1-01 - … on multi-disc albums) or just Title.mp3, and you choose whether to write artwork, tags and genre.

Safe to try

A rename never overwrites another file, and files that don't match a track are left as they are. Undo puts the original names back exactly.

Keeps itself up to date

When it starts, ArtiSync checks GitHub for a new version. It can download and install it in one click, then reopen. The Flatpak saves the new version to Downloads for your software centre to install. Every download is checked against the release's SHA-256 checksum, and you can turn the check off.

9 colour themes

Dark, Light, Midnight, Emerald, Amethyst, Crimson, Forest, Ocean and Slate, in Settings. Try them in the demo above.

Keyboard shortcuts

Ctrl+→ / Ctrl+← next and previous album, Ctrl+Enter Rename & Tag, Ctrl+Z Undo, F5 Refresh, Ctrl+F filter the library, Ctrl+Shift+F search releases, Ctrl+O choose a folder, Ctrl+, Settings.

Convert between audio formats

With FFmpeg, from Convert… or automatically before every rename.

Input formats

MP3FLACM4A AACMP4OGG WAVOPUSWMA

Output formats

MP3FLACM4A OGGWAV

AAC and MP4 to M4A only changes the container, so nothing is lost. Everything else is re-encoded, and cover art is kept where the format supports it. Converting never overwrites a file.

Get ArtiSync

Everything ArtiSync needs is included. Converting audio also needs FFmpeg on your PATH, except in the Flatpak, which brings its own.

Windows 10 / 11

Windows Installer

Adds ArtiSync to the Start Menu, with an optional desktop shortcut.

Download

1. Run ArtiSync-Setup.exe.

2. ArtiSync isn't signed, so Windows may say it protected your PC: choose More info → Run anyway.

3. Open ArtiSync from the Start Menu.

Windows 10 / 11

Windows Portable

No installer: unzip it anywhere and run it, even from a USB stick.

Download

Extract ArtiSync-Portable.zip and run ArtiSync\ArtiSync.exe.

macOS 11+ · Apple Silicon

macOS

A disk image: drag ArtiSync to Applications. There's also the app on its own, as a zip.

Download

1. Open ArtiSync-macOS.dmg and drag ArtiSync to Applications.

2. ArtiSync isn't notarized by Apple, so macOS blocks the first launch. Right-click ArtiSync and choose Open, or allow it under System Settings → Privacy & Security.

Linux · x86-64

Linux · Flatpak

Flatpak

A sandboxed bundle, with FFmpeg included for converting.

Download

Run from source ▼

Needs Python 3.10 or newer. The first run makes a Python environment in ~/.local/share/ArtiSync/venv and installs PySide6, spotipy, thefuzz and mutagen; later runs start straight away.

git clone https://github.com/Spinjitsudoom/ArtiSync
cd ArtiSync
./run.sh

./run.sh --update upgrades those packages. The README has the commands that build each download.

All builds are v3.0.0. Source code available on GitHub.

How it Works

From messy folders to a tagged library

Choose your music folder once, then each album takes a look and a click.

Choose your music folder

Choose the folder that holds your artist folders, like Music/Three Days Grace/Alienation (2025)/…. Everything else is automatic, and Deezer, the default, needs no account.

Check the matches

ArtiSync opens the first unfinished album with every file matched to a track and a confidence score. Amber and red rows are worth a look. If the release is wrong, pick another from Releases, or search for it.

Rename & Tag

One click renames the files and writes the tags and cover art. Undo reverses it. Then Next album (Ctrl+→) moves on through the library.

Undo reverses the last Rename & Tag, until you close ArtiSync.

Use Spotify (optional)

Create a free app at developer.spotify.com/dashboard and copy its Client ID and Client secret. In ArtiSync open Settings, choose Spotify, paste both and Save.
