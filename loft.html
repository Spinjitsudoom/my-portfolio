Self-hosted eBooks

Loft

A self-hosted ebook library with pages that turn like paper. Your books stay where they are: Loft reads them, shelves them, and lets everyone you invite read them on a phone, tablet or computer.

Loft — 192.168.1.20:4545

This is the real Loft web app, running on a made-up library: every book, reader and message in it is invented, and what you change lasts until you leave the page. Open a book and turn the pages (click or drag a page’s edge, or use the arrow keys), tap the middle of a page for the reader’s controls, pull a book off the shelf in the stacks, or search for keeper harbor, typo and all.

Features

A library, not a file list

Everything you'd want from a reading app, running on your own computer and reading your own files.

A library that looks like one

A cover wall at home, and the stacks: every book standing spine-out on bookcases, shelved by series, section or author, with name cards between the authors. Tap a spine and the book slides out. Thicker books get thicker spines.

Pages that turn like paper

Pages curl as you turn them, two side by side on wide screens. EPUB, Kindle and FB2 books are laid out to your font, size and margins, on a Dark, Sepia, White or Black page. Tap the edges to turn, the middle for settings, or switch to scrolling.

The formats you have

EPUB, PDF, CBZ, CBR and CB7 comics, Kindle (MOBI, AZW, AZW3) and FB2, plus plain text if you turn it on. Calibre libraries are recognised, so titles, authors, series and covers come straight from them. Protected (DRM) books are listed but can't be opened.

Comics, manga & picture books

Zoom, two-page scans split into pages, wraparound covers, and manga read right to left. Arrange pages moves, hides or adds blank pages without touching the file. Fixed-layout picture books show each page as designed, in a sealed frame where nothing in the book can run.

Your place, on every device

Your place and bookmarks follow you between devices. Each book has your own reading status: Want to read, Not started, Reading, Incomplete, Abandoned or Finished. Loft keeps it up to date as you read, and Home shows what you're reading and what you stopped.

Search that finds what you mean

Type the words you remember, in any order, and Loft looks through titles, series, authors, tags and descriptions. It forgives typos, missing apostrophes and hyphens, and puts the best matches first. Try it in the demo.

For everyone you invite

Each person has their own place in each book, their own bookmarks and their own shelves. Members can submit books for the admin to approve, and ask for books: others vote, and everyone who asked is told when it arrives. New people can ask to join from the sign-in page.

Talk about books without spoilers

Every book has a discussion, on its page and inside the reader. Each message shows where its writer was in the book, and one from further on than you is blurred until you get there. Tap it to read it anyway.

Offline downloads

Download a book to read it with no connection: comics and PDFs as page images, EPUBs with their pictures. Progress and bookmarks made offline are sent when the server is back, and a book that changes downloads again by itself. The apps open onto your downloads with no connection too.

Your files stay yours

Loft never renames, moves or rewrites your books. Details you edit live in Loft's own database and survive rescans. Books added in Loft are saved into the folder you choose, as Author/Title/file.

Fills in the details

Look up details from Google Books, Open Library or AniList. Library check finds books without covers, authors or tags, damaged or protected files, possible duplicates and gaps in series, then goes through the missing ones with you one by one.

Backs itself up and keeps up to date

A daily backup of accounts, progress, shelves and edits, ideally to another drive, with Restore that can be undone. Loft checks for a new version once a day: the server swaps it in with Restart to update, and the desktop and Android apps update themselves.

Download

Get Loft

Loft has two halves: the server runs on the computer with your books, and the apps (or any browser) are how you read.

1. The server

On the computer, NAS or Raspberry Pi with your books. Nothing else to install.

Windows 10 / 11

Loft Server for Windows

Runs in the background with an icon by the clock, and starts with Windows. Right-click the icon for the address other devices use, Update, and Restart.

Download Portable .zip

1. Run loft-server-0.2.0-windows-x64-setup.exe. If Windows says it protected your PC, choose More info, then Run anyway.

2. Allow Loft through the firewall so other devices can reach it.

3. Click the Loft icon by the clock to open it.

macOS · Apple Silicon

Loft Server for macOS

The whole server in one folder. Unzip it, start it from Terminal, and open Loft in your browser.

Download

1. Unzip it, then in Terminal go into the folder. The first time, clear macOS's block on downloaded programs:

xattr -dr com.apple.quarantine .

2. Start it, then open http://localhost:4545:

./loft-server
Linux · x86-64

Loft Server for Linux

The whole server in one folder, with Python built in. For CBR comics, install unar, unrar or 7z.

Download

Unpack it, go into the folder and start it, then open http://localhost:4545:

./loft-server

To keep it running and start it with the computer, use the systemd service.

Docker · amd64 & arm64

Docker, NAS & Raspberry Pi

The image is ghcr.io/spinjitsudoom/loft. Change the books path in the compose file, then start it. There's also a file for ZimaOS and CasaOS.

docker compose up -d
Compose file

Without Compose:

docker run -d --name loft --restart unless-stopped -p 4545:4545 -v ./loft-data:/data -v /path/to/your/books:/books ghcr.io/spinjitsudoom/loft:latest

ZimaOS / CasaOS: download loft-zimaos.yaml and import it under + → Install a customized app. More in the Docker guide.

2. Apps

On the devices you read on. Each asks once for your server's address (like 192.168.1.20:4545), then opens straight onto your library.

Windows 10 / 11

Loft for Windows

Loft in its own window. From the second start it opens with no connection too, onto your downloaded books, and it updates itself.

Android

Loft Lite

Loft in a small Android app. With no connection it still opens onto your downloaded books, keeps the screen on while you read, adds books from your phone, and updates itself.

Download

1. Open loft-lite-0.2.0.apk on the phone and allow installing from this source.

2. Enter the server's address, e.g. 192.168.1.20:4545, and sign in.

Any browser

Nothing to install

Open the server's address in any browser on a phone, tablet or computer. Over HTTPS you can add it to the home screen and it opens offline.

Run from source (Linux & macOS)▼

Loft needs uv, which fetches the right Python itself. Set books_dirs to your books folder in the config, then start it:

git clone https://github.com/Spinjitsudoom/Loft.git && cd Loft
cp config.example.toml config.toml
bash run.sh

Run the tests with:

bash test.sh -q

All builds are v0.2.0. Source code available on GitHub.

How it Works

From a folder of files to a reading room

Set up the server once, then read anywhere.

Start the server

Run the Windows setup, unpack the macOS or Linux server and start loft-server, or docker compose up -d. Then open http://localhost:4545. The first person to open a new Loft makes the admin account.

Point it at your books

Choose your books folder in Library settings (in Docker, mount it as /books). Loft reads it straight away and looks for new books every 10 minutes. It suggests sections from your books' tags, which you can arrange in Library settings → Sections.

Loft only reads your books folder: it never renames, moves or rewrites a file that's there. Calibre libraries are recognised, with their titles, authors, series and covers.

Invite people

Add people in Library settings → People, or let them ask to join from the sign-in page. They install an app, or open the address in a browser, and sign in.

Read away from home

Loft isn't meant to face the internet, so don't open its port on your router. Install Tailscale on the server and your devices and open http://<server's Tailscale name>:4545. For HTTPS, which lets a phone open the app offline, run sudo tailscale serve --bg 4545.
