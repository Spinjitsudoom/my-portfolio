Features

Everything you need to keep your media library clean, accurate, and ready for any media server.

🔍

Smart Renaming

Two matching modes — numeric order for clean rips, fuzzy title matching for mixed or messy directories. Full undo support so nothing is permanent.

🎬

Movies & TV Shows

Renames both TV episodes (S01E01 format) and movie files with title and release year, keeping Plex and Jellyfin metadata lookups reliable.

🌐

TMDB Integration

Pulls real-time episode titles, air dates, and metadata from The Movie Database API — the same database Plex and Jellyfin use behind the scenes.

💬

Local Subtitle Generation

Generate .srt files offline using faster-whisper. Supports tiny to medium models, VAD filtering, and beam size control. No cloud service or API key required after the initial model download.

⚡

Remux

Batch convert video files between containers (MKV, MP4, AVI…) using FFmpeg stream copy — fast, lossless, no re-encoding.

🎨

9 Themes

Slate, Emerald, Midnight, and six more built-in colour themes. Preferences are saved across sessions.

Getting Started

Up and running in under two minutes.

Get a TMDB API Key

  1. Create a free account at themoviedb.org
  2. Go to Settings → API and generate a v3 key
  3. Paste it into Settings inside the app
Your key is stored locally in ~/Documents/Media Manager/config.json and is never uploaded or hardcoded into the source.

Set Your Library Path

Open Settings and point the app at the root of your media library. The expected structure:

/your/media/root/
  Show Name/
    Season 01/
      episode files...
  Another Show/
  Movie Name (2024)/

Rename Your Files

Select a show and season from the sidebar. Choose Numeric (order-based) or Fuzzy (title-based) matching, review the preview, then click Rename. Use Undo to revert any batch instantly.

Generate Subtitles (optional)

Navigate to the Subtitles tab, select a model size (tiny is fastest, medium is most accurate), and click Generate. The Whisper model downloads automatically on first use and is cached locally. No internet required after that.

FFmpeg must be installed for the Remux feature: sudo apt install ffmpeg (Debian/Ubuntu) or sudo dnf install ffmpeg (Fedora).
