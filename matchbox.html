Features

Everything you need to keep a clean, accurate media library.

🔍

Smart Renaming — Two Modes

Numeric matches files to TMDB episodes by their position in the folder. Title Match uses fuzzy string matching to align filenames to episode titles — useful for mixed or out-of-order directories. Full undo support on every rename.

📺

TV Shows & Movies

Renames TV episodes to Show - S01E01 - Title.mkv format and movie files to Title (Year).mkv — exactly what Plex and Jellyfin expect for automatic metadata matching.

🌐

TMDB Integration

Pulls real-time episode titles, air dates, season posters, and ratings from The Movie Database API — the same database Plex, Jellyfin, and Emby use behind the scenes. Shows auto-match from your folder names.

💬

Local Subtitle Generation

Generate .srt files fully offline using faster-whisper (CTranslate2). Supports tiny → medium model sizes, VAD silence filtering, configurable beam size, and an initial prompt for better accuracy. No API key or cloud service required after the first model download.

⚡

Remux

Batch convert video containers (MKV ↔ MP4 ↔ AVI…) using FFmpeg stream copy — no re-encoding, no quality loss, typically finishes in seconds per file.

🎨

9 Themes

Slate, Dark, Midnight, Emerald, Amethyst, Crimson, Forest, Ocean, and Light. Click Settings in the demo above to try them live.

Download

Get Matchbox

Download and install in seconds — pick your platform.

Windows 10 / 11

Windows Installer

Runs the NSIS setup wizard and adds Matchbox to your Start Menu and Programs list.

⬇ Download

1. Run Matchbox.Setup.1.0.0.exe and follow the wizard.

2. Launch Matchbox from the Start Menu.

3. Point it at your media folder and connect your TMDB API key in Settings.

Windows 10 / 11

Windows Portable

Extract the zip anywhere and run — no installer, no admin rights, no registry entries.

⬇ Download

1. Extract Matchbox-1.0.0-win.zip to any folder.

2. Run Matchbox.exe inside the extracted folder.

Linux · Any distro

AppImage

Single executable — no install needed. Works on any modern Linux distro with FUSE support.

⬇ Download

Make it executable and run:

chmod +x Matchbox-1.0.0.AppImage
./Matchbox-1.0.0.AppImage
Linux · Flatpak

Flatpak

Fully sandboxed, self-contained bundle. No system dependencies required — everything is included.

⬇ Download 
flatpak install --user Matchbox-1.0.0-x86_64.flatpak
flatpak run com.matchbox.app
⚙ Build from Source ▼

Requires Node.js 20+, Python 3.12+, and uv.

git clone https://github.com/Spinjitsudoom/Matchbox
cd Matchbox
uv sync --group dev
cd frontend && npm ci && npm run build
./node_modules/.bin/electron ..

Or use the dev launcher script:

./run.sh

All builds are v1.0.0. Source code available on GitHub.

Getting Started

Up and running in under two minutes.

Get a free TMDB API Key

  1. Create an account at themoviedb.org
  2. Go to Settings → API and request a v3 key
  3. Paste it into Settings inside Matchbox
Your key is stored locally in ~/Documents/Matchbox/config.json and is never uploaded anywhere.

Set your library path

Open Settings and point Matchbox at the root of your media library. Expected folder structure:

/your/media/root/
  Show Name/
    Season 01/
      episode.files...
  Movie Name (2024)/
    movie.file...

Rename your files

Select a show in the left panel — it auto-searches TMDB. Select a season and a local folder. The rename preview populates instantly. Choose Numeric (position-based) or Title Match (fuzzy), review the colour-coded preview, then click Rename Files. Use Undo to revert any batch.

Generate subtitles (optional)

Click Generate in the action bar. Select a model size — tiny is fastest, medium is most accurate. The Whisper model downloads automatically on first use and is cached in ~/.cache/huggingface/. No internet required after that.

The Remux feature requires FFmpeg: sudo apt install ffmpeg or sudo dnf install ffmpeg.
