Features

Everything you need to keep a clean, accurate media library.

🔍

Smart Renaming — Two Modes

Numeric matches files to TMDB episodes by their position in the folder. Title Match uses fuzzy string matching to align filenames to episode titles — useful for mixed or out-of-order directories. Full undo support on every rename.

📺

TV Shows & Movies

Renames TV episodes to 01 - Episode Title.mkv and movie files to Title (Year).mkv. Configure separate root paths for your TV and movie libraries — switch between them instantly with the mode toggle.

✂️

Frame-Accurate Splitting

Split any video at an exact frame with a visual timeline editor. Stream-copies when the cut lands on a keyframe — lossless and instant. Re-encodes only the unaligned head/tail when it doesn't. Auto-names segments from the source filename.

🌐

TMDB Integration

Pulls real-time episode titles, air dates, season posters, and ratings from The Movie Database API — the same database Plex, Jellyfin, and Emby use behind the scenes. Shows auto-match from your folder names.

💬

Local Subtitle Generation

Generate .srt files fully offline using faster-whisper (CTranslate2). Supports tiny → large model sizes, VAD silence filtering, configurable beam size, language, and initial prompt. No cloud required after the first model download.

⚡

Remux

Batch convert video containers (MKV ↔ MP4 ↔ AVI…) using FFmpeg stream copy — no re-encoding, no quality loss, typically finishes in seconds per file. Set default audio and subtitle tracks per conversion.

🎨

9 Themes + 3 Custom

Slate, Dark, Midnight, Emerald, Amethyst, Crimson, Forest, Ocean, and Light — plus three fully customisable colour slots. Click Settings in the demo above to try them live.

Download

Get Matchbox

Download and install in seconds — pick your platform.

Windows 10 / 11

Windows Installer

Runs the Inno Setup wizard and adds Matchbox to your Start Menu with an optional desktop shortcut and a clean uninstaller.

⬇ Download

1. Run Matchbox-Setup-2.0.0.exe and follow the wizard.

2. Launch Matchbox from the Start Menu.

3. The first-run wizard will ask for your TMDB API key and library paths.

Windows 10 / 11

Windows Portable

Extract the zip anywhere and run — no installer, no admin rights, no registry entries.

⬇ Download

1. Extract Matchbox-2.0.0-portable-win.zip to any folder.

2. Run Matchbox.exe — no install, no registry changes.

Linux · Any distro

AppImage

Single executable — no install needed. Works on any modern Linux distro with FUSE support.

⬇ Download

Make it executable and run:

chmod +x Matchbox-2.0.0.AppImage
./Matchbox-2.0.0.AppImage
Linux · Flatpak

Flatpak

Fully sandboxed, self-contained bundle. No system dependencies required — everything is included.

⬇ Download

Install for your user only (no password needed):

flatpak install --user Matchbox-2.0.0-x86_64.flatpak

Or system-wide (requires sudo):

sudo flatpak install Matchbox-2.0.0-x86_64.flatpak

Then launch:

flatpak run io.github.Spinjitsudoom.Matchbox
⚙ Build from Source ▼

Requires Node.js 20+, Python 3.14+, and uv.

git clone https://github.com/Spinjitsudoom/Matchbox
cd Matchbox
uv sync --group dev
cd frontend && npm ci && npm run build
./node_modules/.bin/electron ..

Or use the dev launcher script:

./run.sh

All builds are v2.0.0. Source code available on GitHub.

How it Works

Clean library in four steps

Matchbox handles everything from initial setup to frame-accurate splits.

First-run setup wizard

On first launch, a guided wizard collects your TMDB API key (free at themoviedb.org) and your separate TV and Movie library root paths. Everything is stored locally in ~/Documents/Matchbox/config.json — nothing is uploaded.

Browse your library and match to TMDB

The left panel lists every show or movie folder in your library. Expand a show to reveal its season folders. As you select a folder, Matchbox auto-searches TMDB — pick the right result in the right panel and the rename preview populates instantly.

Expected structure: Show Name / Season 01 / episode.files for TV and Movie Title (Year) / movie.file for movies.

Review and rename

Every file is colour-coded: green = confident match, yellow = fuzzy match, red = no match. Switch between Numeric (position-based) and Title Match (fuzzy string) modes, adjust the file offset if needed, then click Rename Files. One click undoes the entire batch.

Split, subtitle, or remux (optional)

Split opens a frame-accurate timeline editor — set a split point, and Matchbox stream-copies from the keyframe with a lossless smart re-encode only where needed. Auto-names the segments from the source filename. Generate produces offline .srt subtitles via faster-whisper. Remux converts containers with FFmpeg stream copy.

Splitting and Remux require FFmpeg. If it isn't on your system, Matchbox offers a one-click download from Settings.
