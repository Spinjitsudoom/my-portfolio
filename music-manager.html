Music Manager Ultimate

Cross-platform music library organiser — fetches metadata from Spotify, renames files, writes tags, downloads cover art, and converts audio formats.

View on GitHub

Overview

Music Manager Ultimate is a cross-platform music library organiser available as both a Python desktop app and a compiled C++/Qt6 application. It connects to the Spotify API to automatically detect artists, fetch album art, match your local audio files to the correct track names, and write clean embedded tags — all in one step.

How It Works

  1. Browse — point the app at a folder containing artist sub-folders.
  2. Auto-detect — the app searches Spotify and populates the releases sidebar with album art thumbnails.
  3. Select a release — click any album or single to fetch its full track list and cover art.
  4. Match — the fuzzy matcher maps your local files to the correct track names using edit-distance scoring.
  5. Preview — the Preview tab shows exactly which files will be renamed, with per-track confidence scores.
  6. Execute — click Execute Rename + Tag to rename files, write all embedded tags, and embed cover art.
  7. Undo — every rename operation can be fully reversed.

Python — Getting Started

Install dependencies

pip install customtkinter pillow spotipy thefuzz mutagen

Run

cd "python source code"
python music_organizer.py

FFmpeg must be on your PATH for audio conversion to work.

C++/Qt6 — Build from Source

Install dependencies (Fedora)

sudo dnf install cmake gcc-c++ qt6-qtbase-devel openssl-devel

Build

cd "c++ source code"
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
./build/MusicManager

Spotify API Setup

  1. Go to developer.spotify.com/dashboard and create a free app.
  2. Copy the Client ID and Client Secret.
  3. In the app: File → Settings, paste both values, click Save.

A green status dot in the status bar confirms the connection is active.
