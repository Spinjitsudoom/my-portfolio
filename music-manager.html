Everything you need to clean up your library

🎵

Spotify Metadata

Search any artist, browse every release with album art thumbnails, and pull accurate track names, years, and genres directly from Spotify's database.

🔍

Fuzzy File Matching

Automatically maps your local audio files to the correct tracks using edit-distance scoring — works even with messy or incomplete filenames.

🏷️

Tag Writing

Embeds artist, album, title, year, genre, track number, disc number, and cover art into ID3v2 (MP3), Vorbis (FLAC/OGG), and MP4/M4A atoms.

🖼️

Cover Art

Downloads the highest-resolution image from Spotify's CDN and embeds it into your files. Sidebar shows 64×64 thumbnails for every release as they load.

🔄

Audio Conversion

Convert between MP3, FLAC, M4A, OGG, and WAV via FFmpeg. AAC↔M4A is remuxed losslessly; all other pairs use Low / Medium / High / Best quality presets.

↩️

Preview & Undo

See exactly which files will be renamed before committing. Every execute operation can be fully reversed with a single click.

📁

Batch Mode

Process an entire artist directory in one click — the app auto-detects and matches every album sub-folder without manual selection.

🎨

9 Colour Themes

Dark, Light, Midnight, Emerald, Amethyst, Crimson, Forest, Ocean, and Slate — switch instantly from File → Settings.

How it works

1

Browse to your music folder

Point the app at a root directory containing artist sub-folders. The path is remembered between sessions.

2

Artist is auto-detected

The app searches Spotify for the folder name and populates the releases sidebar with album art thumbnails loading in the background.

3

Select a release

Click any album or single. The app fetches the full track list, cover art, and metadata from Spotify.

4

Review the match preview

The Preview tab shows every file → new name mapping with a confidence percentage. High-confidence matches are green; uncertain ones are amber.

5

Execute Rename + Tag

One click renames all files, writes embedded tags (title, artist, album, year, genre, track number), and embeds the cover art.

6

Undo if needed

Changed your mind? Hit Undo to restore the original filenames instantly.

Frequently asked questions

Do I need a Spotify Premium subscription?

No — a free Spotify account is enough. The app only uses the Spotify Web API for metadata (artist names, album art, track listings). It does not stream or play music.

What audio formats are supported?

For renaming and tag writing: MP3, FLAC, M4A, OGG, and WAV. For audio conversion via FFmpeg: the same five formats, with AAC↔M4A handled as a lossless remux and all other pairs transcoded.

Does it work offline?

An internet connection is required to fetch metadata and cover art from Spotify. The rename and tag-write operations themselves run entirely locally once metadata has been fetched.

Is FFmpeg required?

Only for the audio conversion feature (File → Convert). Renaming and tag writing work without FFmpeg. If conversion is attempted without FFmpeg on your PATH, the app will show a clear error.

Can I undo after closing the app?

Undo is available within the same session. Closing the app clears the undo history. It's recommended to use the Preview tab to verify all renames before executing.

Is there a Python version?

Yes — the python source code/ directory in the repository contains a fully functional Python version using customtkinter. Run it with python music_organizer.py after installing the dependencies.

Where are my Spotify credentials stored?

Your Client ID and Secret are stored locally in a config.json file in the app's directory. They are never transmitted anywhere other than directly to Spotify's API.

Python — Getting Started

Install dependencies

pip install customtkinter pillow spotipy thefuzz mutagen

Run

cd "python source code"
python music_organizer.py

FFmpeg must be on your PATH for audio conversion to work.

C++/Qt6 — Build from Source

Fedora / RHEL

sudo dnf install cmake gcc-c++ qt6-qtbase-devel openssl-devel

Ubuntu / Debian

sudo apt install cmake g++ qt6-base-dev libssl-dev

Build

cd "c++ source code"
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
./build/MusicManager

Spotify API Setup

  1. Go to developer.spotify.com/dashboard and create a free app.
  2. Copy the Client ID and Client Secret.
  3. In the app: File → Settings, paste both values, click Save.

A green status dot in the status bar confirms the connection is active.
