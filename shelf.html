Self-hosted Music

Shelf

A self-hosted music server for your own CD rips, with the features of a big streaming app. It scans a folder of music, lays it out as a shelf of albums, and streams it to every browser, phone and computer in the house, for everyone you add.

Features

Everything you'd expect from a big streaming app, running on your own computer and playing your own files.

Your music, everywhere

Stream to any browser (desktop, phone or TV), the native Android app with Android Auto, lock-screen controls and a home-screen widget, and desktop players for Windows and Linux with media-key support. Pick a device under Play on and the music moves there, picking up at the same spot.

Accounts for everyone

The music is shared, but each person has their own Favourites, playlists, history and devices. An admin dashboard adds people, resets passwords, shows two weeks of listening, and runs rescans and storage.

Made for you

Shelf Mixes, On Repeat, Discover, song and artist radio, and mood mixes (Workout, Chill, Party, Feel Good, Melancholy and Heavy), new every day and drawn as mix tapes. Songs are matched on how they actually sound as well as artist, genre, tempo and key, and suggestions learn from the songs you skip.

Make a playlist from a few words

Type “metal, high energy”, “chill 90s” or “like Metallica” and Shelf builds the playlist from your library, matching genres, artists, moods, energy and decades. No AI model: it works from what Shelf has measured and knows. Try it in the demo with + in Your Library.

A native Android app

Built with Kotlin, Compose and Media3: swipe to skip, synced lyrics, editable playlists, offline downloads, Android Auto, and Now Playing as a jewel case or a spinning record. It plays on with the screen off or the app swiped away. Shelf Lite stays available for older phones.

Keeps itself up to date

The server installs new releases by itself at night, between 2 and 6, once nothing has played for half an hour, so music is never cut off. You can switch that off on the admin dashboard and use Update now instead. The Android app and the desktop players download updates in the background.

DJ-style Mix transitions

Turn on Mix and a playlist plays like a DJ set: Blend, Bass swap, Rise, Fade or Cut between songs, beat-matched and tempo-adjusted. Edit any transition on a two-waveform timeline.

Playlists like a DJ app

BPM and key columns in Camelot notation, coloured around the wheel so compatible keys stand out. Recommended suggests songs from your library that fit by artist, genre, tempo and key.

Together

Party mode: guests join from their own phones, add songs to the queue and vote to skip, and can play along in step with the host. Plus public and collaborative playlists, Friend activity, and Blends, a daily playlist for two built from what you both listen to.

Your listening & Wrapped

Time listened, your daily streak, top artists, songs, albums and genres, when you listen by hour and weekday, artists new to you, and On this day, for this month, this year or all time. Wrapped steps through your year one card at a time and ends with your top songs to play. Each person can also scrobble their plays to Last.fm and ListenBrainz, from any device.

Offline downloads

Download albums, playlists and Favourites to the device. Downloaded playlists follow your changes, and plays made offline go into your history when you're back online.

Lyrics & music videos

Timed lyrics that light up line by line, from .lrc files, tags or LRCLIB. When a song has an official video, Switch to video picks it up where the song was, and switches back the same way.

Getting music in

Upload songs, folders or ZIPs from the browser, drop them in a watch folder to be renamed from their tags and filed by artist and album, or rip a CD in the server's drive. It gets tags and cover art from MusicBrainz, rips to FLAC with cd-paranoia, and files it. Not on your shelf lists your artists' releases that you don't have yet.

Sound settings

Gapless playback, crossfade, loudness normalization (album-aware), a 6-band equalizer with a draggable curve, balance, mono, and separate Wi-Fi and mobile streaming quality up to lossless. In the browser and the Android app, Now Playing has a visualizer: a ring of bars around the disc that moves with the music in the album's colour.

Private by default

Fonts and icons are served by Shelf itself. Each outside lookup (lyrics, videos, artist info, new releases) sends only artist, title and album names, and each one can be turned off in config.toml.

Download

Get Shelf

Shelf has two halves: the server runs on the computer with your music (one per household), and players run on the devices you listen on.

1. The server

Install this on the computer with your music.

Linux · Any distro

One-line install

Installs everything except ffmpeg and keeps Shelf running in the background, starting with the computer. Run it again to update.

curl -fsSL https://raw.githubusercontent.com/Spinjitsudoom/shelf/main/install.sh | bash

1. Install ffmpeg first, e.g. sudo apt install ffmpeg (or your distribution's equivalent).

2. Run the command above, then open http://localhost:4533.

To remove it (your library data is kept):

curl -fsSL https://raw.githubusercontent.com/Spinjitsudoom/shelf/main/install.sh | bash -s -- --uninstall
Windows 10 / 11

Shelf Server for Windows

Sits in the notification area (Open Shelf, Start with Windows, Quit), with ffmpeg built in, and measures tempo, key and "sounds like" just like the Linux server. CD ripping needs the Linux server.

Download

1. Run Shelf-Server-Setup-0.7.4.exe.

2. When Windows asks whether to let it on the network, allow it so your phone can reach it.

3. Choose Open Shelf from the tray icon.

Run from source ▼

Any system with uv and ffmpeg on the PATH.

git clone https://github.com/Spinjitsudoom/shelf
cd shelf
cp config.example.toml config.toml   # optional: music_dirs, admin password
bash run.sh

Run the tests with:

UV_PROJECT_ENVIRONMENT=~/.local/share/shelf/venv uv run pytest

2. Players

On the devices you listen on. Each asks for your server's address (like 192.168.1.20:4533), then you sign in.

Android 8+

Shelf for Android

The full native app (about 13 MB): offline downloads, Android Auto, a home-screen widget, lock-screen and Bluetooth controls, and it updates itself from GitHub.

Download APK

1. Open Shelf-0.7.4.apk on the phone and allow installing from this source.

2. Enter the server address, e.g. 192.168.1.20:4533 at home, or a Tailscale name away from it.

3. Sign in. Add the widget by long-pressing the home screen → Widgets → Shelf.

It replaces the older Android app in place: open it once and sign in again. Anything downloaded in the old app needs downloading again.

Android 5+

Shelf Lite

The lightweight app (under 100 KB) for older or low-storage phones: Shelf's web app full screen, with a media notification, the widget and background play. It gets new web features first, and installs beside the full app.

Download APK
Windows 10 / 11

Windows player

A desktop app for Shelf that works with your keyboard's media keys and the Windows playback controls.

Download

1. Run Shelf-Setup-0.7.4.exe.

2. Enter your server's address and sign in.

Linux · Debian / Ubuntu / Mint

.deb package

The desktop player for Debian-based distributions. Works with media keys and the desktop's own playback controls (MPRIS).

Download 
sudo apt install ./shelf_0.7.4_amd64.deb
Linux · Flatpak

Flatpak

The same desktop player as a sandboxed bundle that runs on any distribution.

Download

Install for your user (no password needed):

flatpak install --user Shelf-0.7.4.flatpak

Then launch:

flatpak run io.github.spinjitsudoom.Shelf
Any browser

Nothing to install

Open the server's address in any browser on a phone, computer or TV. On a phone you can add it to the home screen. Over HTTPS it also works offline.

All builds are v0.7.4. Source code available on GitHub.

How it Works

From CD rips to every room

Set up the server once, then listen anywhere.

Install the server

Run the one-line installer on Linux or the setup program on Windows, then open http://localhost:4533. The first time, Shelf asks you to create the admin account. After that it keeps itself up to date, installing new versions overnight when nothing is playing.

Point it at your music

Add your music folders in Settings. The first scan starts straight away; after that, new music is picked up every 10 minutes. In the background, Shelf measures each song's loudness, tempo, key and sound for normalization, Mix and recommendations.

Albums are the tracks in one folder sharing an album tag, so CD1 / Disc 2 subfolders count as one album. Covers come from cover.jpg, folder.jpg or embedded art.

Add people and devices

Create accounts for everyone in the admin dashboard. Install a player, or open the address in a browser, enter the server address and sign in. Every open device shows up under Play on.

Listen away from home

Use Tailscale on the server and your devices rather than exposing the port to the internet. sudo tailscale serve --bg 4533 gives you an HTTPS address on every device in your tailnet, which also enables offline mode and home-screen install in the browser.
