TMDB Media Manager

Automated TV show renaming for Plex, Jellyfin, and Emby — powered by The Movie Database.

View on GitHub

Overview

Media Manager Ultimate is a Python GUI utility that organizes your media library by syncing local files with The Movie Database (TMDb). It ensures your shows are named perfectly so that media servers like Plex and Jellyfin can fetch metadata, posters, and episode summaries without errors.

Features

🔍

Fuzzy Title Matching

Automatically pairs messy filenames with official episode titles using string similarity scoring.

🔢

Sequential Numeric Matching

Quickly renames files based on their directory order — perfect for new season rips.

🌐

TMDb Integration

Pulls real-time data from the official TMDb API for accurate episode titles and metadata.

🎨

Dynamic Theme Engine

Supports 9 visual styles (Slate, Emerald, Midnight, and more) with a zero-glare dark mode.

🛡️

Preview Mode

See exactly what will happen before a single file is renamed. Nothing changes until you confirm.

Getting Started

1. Install dependencies

pip install -r requirements.txt

2. Launch the app

python media_dashboard.py

Linux users: if the app fails to open, install Tkinter — sudo apt install python3-tk (Debian/Ubuntu) or sudo dnf install python3-tkinter (Fedora).

TMDb API Setup

  1. Sign up for a free account at TheMovieDB.org and generate a v3 API key.
  2. Launch the application and go to File → Settings.
  3. Paste your key into the TMDb API Key field and click Save Settings.

Your key is stored locally in config.json and is never uploaded or hardcoded into the source.
